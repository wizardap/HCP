# Design Specification: Dynamic Solver Re-seeding & Inprocessing Engine (`SolverReseeder`)

- **Date:** 2026-08-28
- **Target Repository:** `wizardap/HCP` (`src/cegar-fix`)
- **System Constraints:** Core 3 must ALWAYS be left free for the user. Single/Multi-core commands use `taskset -c 0,1,2 nice -n 19`. Time limit $T_{\max} = 1800\text{s}$.

---

## 1. Executive Summary & Problem Context

### 1.1 The $T_{\text{SAT}}$ Latency Creep Problem
During empirical benchmarks on large challenge instances (`graph651`, `graph479`, `graph668`, `graph788`), the SAT solver exhibits latency inflation over iterative CEGAR rounds:
- In Round 0, CaDiCaL solves the base formula in **0.3s – 1.0s**.
- By Round 20–30, despite `CutSelector` keeping added cut clauses bounded ($< 2,000$ clauses), CaDiCaL accumulates hundreds of thousands of internal learned clauses, activity scores, and restart states.
- Consequently, $T_{\text{SAT}}$ creeps up to **30s – 85s** per iteration, choking outer CEGAR loop throughput to only 15–20 iterations per 300s.

### 1.2 The Solution: Dynamic Solver Re-seeding (`SolverReseeder`)
- Detect when $T_{\text{SAT}}$ exceeds an adaptive threshold (e.g. $T_{\text{SAT}} > 15\text{s}$ or outer iteration count is a multiple of $N_{\text{refresh}} = 10$).
- Construct a fresh CaDiCaL solver instance, re-load the clean base encoding CNF, re-load all accumulated budgeted cut clauses from `CutSelector`, and re-apply active `BackboneFreezer` assumptions.
- This purges all inactive learned clauses and solver drag, resetting per-round $T_{\text{SAT}}$ back down to **$\le 1\text{s} - 3\text{s}$**, increasing CEGAR throughput by **$5\times - 10\times$** in the same execution budget.

## 2. Mathematical Formalization & Soundness

### 2.1 Invariant Preservation
Let $\mathcal{F}_{\text{base}}$ be the initial HCP degree-1 in/out CNF formula.
Let $\mathcal{K} = \{K_1, K_2, \dots, K_t\}$ be the set of valid cut clauses generated by `CutSelector` across iterations $1 \dots t$.
Each $K_i$ is a mathematically valid clause that refutes a subcycle or enforces a boundary cut.
When re-seeding the solver at iteration $t$, the new solver state is initialized with:
$$\mathcal{F}_{t} = \mathcal{F}_{\text{base}} \cup \bigcup_{i=1}^t K_i$$
Because $\mathcal{F}_t$ contains the exact same sound logical constraints as the cumulative formula, the re-seeded solver preserves 100% soundness and completeness with zero loss of refutation power.

## 3. Architecture & Code Changes

### 3.1 `src/cegar-fix/src/solver_reseeder.rs`
- Create `SolverReseeder` module:
  ```rust
  use rustsat::instances::Cnf;
  use rustsat::solvers::{Solve, SolverResult};
  use rustsat_cadical::CaDiCaL;

  #[derive(Debug, Clone)]
  pub struct ReseederOptions {
      pub max_sat_time_threshold_secs: f64, // Default: 15.0s
      pub periodic_interval_rounds: usize,  // Default: 10 rounds
      pub enable_reseeding: bool,           // Default: true
  }

  impl Default for ReseederOptions {
      fn default() -> Self {
          Self {
              max_sat_time_threshold_secs: 15.0,
              periodic_interval_rounds: 10,
              enable_reseeding: true,
          }
      }
  }

  pub struct SolverReseeder;

  impl SolverReseeder {
      pub fn should_reseed(
          last_sat_time_secs: f64,
          current_round: usize,
          options: &ReseederOptions,
      ) -> bool {
          if !options.enable_reseeding || current_round == 0 {
              return false;
          }
          last_sat_time_secs >= options.max_sat_time_threshold_secs
              || (current_round % options.periodic_interval_rounds == 0)
      }

      pub fn reseed_solver(
          base_cnf: &Cnf,
          accumulated_cuts: &[Cnf],
      ) -> Result<CaDiCaL<'static, 'static>, String>;
  }
  ```

### 3.2 `src/cegar-fix/src/hcp_solver.rs`
- In `solve_hcp_with_cegar`:
  - Store a clone of `base_cnf` and keep a cumulative list of `accumulated_cut_cnfs`.
  - In each outer iteration, check `SolverReseeder::should_reseed(sat_solving_time.as_secs_f64(), count, &reseeder_opts)`.
  - If true, call `SolverReseeder::reseed_solver(&base_cnf, &accumulated_cut_cnfs)` to instantiate a fresh CaDiCaL instance.
